## Two integrity issues this audit surfaced

**1. Silent degeneration of the semantic ablation.** The semantic detector fails open when its cache is missing — correct behaviour for a gateway, and a hazard for an experiment. L/M collapsed onto C/E and the artifact still looked well-formed, with plausible numbers. `audit_evidence.py` now detects the collapse by equality-checking L against C. **The +1.2pp figure quoted in earlier prose is not reproducible here** and must be regenerated on a machine with the cache before it can be published.

**2. Inconsistent CI schema across artifacts.** `statistical_validation.json` writes `ci95_low`/`ci95_high`; `threshold_study.json` writes `ci95: [lo, hi]`. Normalised at read time and reported; worth unifying at write time.

## Reproducing

```bash
python scripts/audit_evidence.py     # rebuilds dataset/processed/evidence_audit.json
```

The audit is deliberately pessimistic: anything it cannot verify from an artifact is marked UNSAFE, including findings that are probably true.
